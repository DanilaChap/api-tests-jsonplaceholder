# ApiTests
## auto-tests REST API on https://github.com/DanilaChap/api-tests-jsonplaceholder

## What is covered
- GET
- POST
- PUT
- DELETE
- Positive and negative tests
- Parametrisation
- Fixture
## Tech stack
- Python
- pytest
- requests
- ruff
